# Student Feedback Management System

## 📌 Project Description
This is a Student Feedback Management System built to collect and manage student feedback efficiently. It helps institutions gather responses and improve academic quality.

## 🚀 Features
- Student feedback submission
- Admin dashboard
- View and manage feedback
- Database integration

## 🛠️ Technologies Used
- Python / Flask (or Django if applicable)
- HTML, CSS, JavaScript
- MySQL
- AWS EC2 deployment
- Git & GitHub
